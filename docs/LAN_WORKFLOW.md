# 本地／局域网工作流（0.3）

Mac 运行一个应用进程，浏览器通过局域网访问。上传、模型、SQLite、抽帧和导出都使用启动时指定的 `--data-dir`；不会调用原平台服务。

## 续传上传

浏览器先用项目自带的 Worker 分块计算完整 SHA-256，不依赖 HTTPS 或 Web Crypto，也不把整个视频读进内存。选择相同内容时，服务端返回原上传会话和已确认的字节偏移，随后逐块继续：

- 默认每块 8 MiB，附 SHA-256 和字节偏移；服务端校验、写盘及 `fsync` 后才提交 SQLite 进度。
- 丢失回复可重复发送相同分块；偏移冲突会重新查询进度，内容不一致会拒绝。
- 最终校验整文件摘要并执行 `ffprobe`，成功后才登记病例。完成请求和重新选择已完成的同一文件不会重复建档。
- 暂停不删除已保存分块。刷新或重启后重新选择同一文件即可续传；浏览器不能在重启后自行取得原文件访问权，因此需要这一步选择。
- 未完成会话按最后确认分块保留 7 天，启动服务或创建上传时清理过期分块。每台服务最多同时保留 32 个有效未完成会话。
- 完成上传的数据库提交前保留分块文件。支持硬链接的磁盘不额外复制；其他磁盘在完成时复制一次，因此需要额外磁盘空间。

原始流式上传接口仍可使用；浏览器使用新的续传接口。

| 接口 | 用途 |
| --- | --- |
| `POST /api/upload-sessions` | 文件名、大小和完整摘要建立或恢复会话 |
| `GET /api/upload-sessions/{id}` | 已确认偏移及完成结果 |
| `PUT /api/upload-sessions/{id}` | `Upload-Offset`、`X-Chunk-Sha256` 和二进制分块 |
| `POST /api/upload-sessions/{id}/complete` | 完整校验并入库 |
| `DELETE /api/upload-sessions/{id}` | 丢弃未完成上传 |

## 自动及批量 AI

上传后自动分析默认开启，可在视频库关闭，设置保存在 SQLite。关闭后不再提交尚未执行的上传自动请求，已提交任务继续。批量按钮是明确提交，不受上传自动开关影响。

请求先进入持久等待队列。模型缺失时显示等待配置，运行队列满时等待空位；调度器每两秒检查，最多向单工作线程提交八个排队／运行任务。批量每次选择 1–100 个病例，跨页选择保留；逐病例显示加入或跳过原因。

自动及批量调度跳过已复核、已有阶段／征象、已有运行任务或待确认结果的病例，并在真正提交的数据库事务中复查，保护调度期间的新编辑。提交保存标注版本和权重摘要。结果保存在独立任务中，必须明确确认应用；如标注版本已变化则拒绝应用，已有征象也拒绝覆盖。

重启会把已经提交的排队／运行任务标记为中断，避免无提示重跑。尚在等待配置或空位的请求仍保留；用户可以对中断或失败病例重新提交批量分析。

`GET/PATCH /api/settings` 读写 `auto_analyze_uploads`；`POST /api/analysis-batches` 接收 `video_ids`，返回逐病例状态。

## 实际裁剪框

AI 成功时，适配器读取参考预处理返回的逐时段 `box`，保存原视频 SHA-256、宽高、任务、模型和预处理来源，转换为播放器的 `sam-workflow.video-crop.v1` 记录。原参考 `_features` 和 `AdaptiveFOV` 均未修改。

播放器按当前时间选择矩形，并对原始像素坐标进行等比缩放和留白补偿；可显示／隐藏。先打开播放器、AI 后完成时，后台轮询会自动取得新记录，无需刷新或保存。实际全帧回退会显示全幅框，没有记录时不画框，尺寸或时段无效会报错。叠加只帮助查看模型的输入区域，不裁剪播放文件或导出的原尺寸图像帧。

## 整例删除

单例和批量共用删除实现。先预览病例、标注、完整抽帧记录和缓存包数量，确认后再核对内容指纹；标注、病例资料、复核、任务或关联导出发生变化时返回 409，要求重新预览。

有排队或运行中的分析／抽帧任务时不删除。删除覆盖原视频、所有表标注、病例资料、抽帧目录、AI 结果、裁剪记录、自动请求及相关服务端病例 ZIP；旧版本生成的有效缓存包会在启动时补建索引。一个缓存 ZIP 含多个病例时，删除其中任一病例会删除该整个缓存包，其余病例仍可重新导出。

文件先移入带日志的本地隔离目录，再提交数据库。操作失败会恢复整批；进程中断后，启动根据 SQLite 是否已删除这些病例来恢复文件或清理隔离目录。病例审计中的原始标注内容也一并清除，只保留此次删除的内部 ID 和数量。已经下载到浏览器设备的文件需自行管理。

`POST /api/cases/delete-preview` 接收 `video_ids`；`POST /api/cases/delete` 另外提供预览 `token` 和 `confirm_count`。

## 验证边界

接口测试使用临时数据和合成视频，覆盖续传重启、丢失确认、未提交尾部、校验失败、调度保护和队列空位、删除回滚和恢复。浏览器在普通 HTTP 的局域网式地址上运行，不提供 Web Crypto，实际操作续传、多分块、设置、批量分析等待、整例删除及完整人工标注／导出流程。

裁剪叠加和 AI 应用策略使用明确的合成记录测试。没有安装模型时不会生成推理结果。这些检查不证明真实模型输出、MPS 性能或 Neural Engine 可用；仍需目标 Mac mini 和实际权重验收。
